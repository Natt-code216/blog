COSMIC ATELIER / 星夜里的私人展厅
第二轮视觉研究 · 2026-10-03

最新方向
保留用户已经认可的宇宙 Hero。把下半页延续成同一个深色宇宙空间，
用梵高式的旋涡笔触、向日葵金色和莫奈式水面光色组成原创油画场景。
本文件是新一轮研究与建议，替代上一轮“深色首屏转暖白正文”的方向。
前半部分保留研究阶段的建议，最终落地结果见文末。

已核查的原始参考与用途

01 / Atmospheric Depth Gallery
代码：https://github.com/houmahani/codrops-depth-gallery
演示：https://tympanus.net/Tutorials/DepthGallery/
许可：仓库明确标注 MIT；README 的图片来源为 Lummi.ai。
原始效果：Three.js 深度画廊，图像各自决定环境配色，滚动速度影响氛围。
建议借鉴：把文章预览当作空间中的一幅画，近处清晰、远处隐约；每个
章节有不同的环境色，但都保持同一深色基底。
应用位置：随笔展厅与章节背景过渡。不要要求用户穿过一条长画廊才能
看到最后一篇文章；内容目录需要始终可以快速扫读和直接进入。
成本判断：中高；采纳图层深度和配色关系即可，不必复刻整个滚动世界。

02 / 3D Infinite Carousel with Reactive Background Gradients
代码：https://github.com/clementgrellier/gradientslider
演示：https://tympanus.net/Tutorials/3DGradientCarousel/
教程：https://tympanus.net/codrops/2025/11/11/building-a-3d-infinite-carousel-with-reactive-background-gradients/
许可：仓库标注 MIT。
原始效果：DOM 画面通过 rotateY、translateZ 与 scale 形成弧形空间，
背景 Canvas 根据当前图片的颜色改变氛围。
建议借鉴：水平展览可以用真实 HTML 与 CSS 透视完成，不必将文字
渲染进 WebGL。中央画面突出，旁边保留下一幅的轮廓。
导航改造：本项目使用有限数量、可见的标题目录与前后按钮；可选拖动
仅用于画作浏览。原教程拦截 wheel 的做法不采用。纵向滚动始终正常。
成本判断：中等；不用无限循环、不每帧取色，可预设每张图的氛围色。

03 / Shader Based Reveal Effect with React Three Fiber & GLSL
代码：https://github.com/colindmg/r3f-image-reveal-effect
演示：https://tympanus.net/Tutorials/R3FImageReveal/
教程：https://tympanus.net/codrops/2024/12/02/how-to-code-a-shader-based-reveal-effect-with-react-three-fiber-glsl/
许可：仓库明确标注 MIT；示例图为作者通过 Midjourney 生成。
原始效果：Perlin 噪声与径向渐变控制 alpha，配合轻微的顶点波动揭示图像。
建议借鉴：油画从星尘中缓慢浮现；蒙版边缘像颜料扩散，原图中心保持
稳定。适合章节首次入场或切换预览，持续强烈扭曲会损伤油画笔触。
成本判断：中等；一次只显示一个活动舞台，离开视口时暂停。
兼容：现有 React 18 若引入 Fiber，应使用 v8；也可把同一 shader
思路直接用于已经使用的 Three.js，避免引入新的 React 渲染生态。

04 / Animating WebGL Shaders with GSAP
代码：https://github.com/biazo/codrops-animate-shaders-with-gsap
教程：https://tympanus.net/codrops/2025/10/08/how-to-animate-webgl-shaders-with-gsap-ripples-reveals-and-dynamic-blur-effects/
许可：示例代码仓库明确标注 MIT，GSAP 等依赖使用各自许可。
原始效果：通过 uniform 驱动纹理混合、指针起点的径向揭示、波纹和模糊。
建议借鉴：在两幅油画之间用 uProgress 混合纹理，让向日葵逐渐溶进
星空。预览可以 650–900ms 完成交叉淡化，目录高亮在输入后立即响应。
成本判断：中等；主要使用两张纹理 + 一个平面。不要为每一行创建 Canvas。
退化路径：原生 img 叠层 opacity 同样可以形成优雅的淡化；可保留为
低性能设备、WebGL 不可用和减少动态效果模式的版本。

05 / Sticky Grid Scroll
代码：https://github.com/theoplawinski/codrops-sticky-grid-scroll
演示：https://tympanus.net/Tutorials/StickyGridScroll/
教程：https://tympanus.net/codrops/2026/03/02/sticky-grid-scroll-building-a-scroll-driven-animated-grid/
许可：仓库明确标注 MIT；依赖 GSAP、Lenis 使用各自许可；图片来源 Lummi。
原始效果：sticky 区域内的图片网格按照滚动进度逐步组织、展开。
建议借鉴：左侧或右侧常驻一块油画舞台，另一侧是正常文档流的目录。
目录行进入视口中央时更新活动场景。桌面 sticky 负责位置，原生滚动
负责导航，不用监听 wheel 后 preventDefault。
成本判断：低至中等；IntersectionObserver 配合少量 CSS 即可完成
场景状态切换，不一定需要安装 GSAP/Lenis。

06 / On-Scroll Image Layout Animations
代码：https://github.com/codrops/ScrollBasedLayoutAnimations
演示：https://tympanus.net/Development/ScrollBasedLayoutAnimations/
许可：仓库明确标注 MIT；示例使用 GSAP ScrollTrigger 与 Flip。
原始效果：滚动时图片在不同构图布局之间连续变化。
建议借鉴：章节之间让一个画面从宽幅背景收束为一块展品，再把阅读
目录显露出来。真正需要连续空间感的是章节交接处，不是每一段文字。
成本判断：中等；本次可以用单次 scale/opacity/translate 的淡入方案
传达相同节奏，避免长距离固定滚动造成访问效率下降。

许可说明
上述 MIT 指仓库公开标注的代码许可，不把第三方图片或依赖自动视为
同一许可。此轮只研究效果与结构，不复制演示素材；正式配图使用本项目
生成的原创作品。具体的架构、性能与信息设计建议为结合仓库作出的判断。

新的信息架构：一个展厅，四种内容效率

00 / 入口
保持当前 Hero 的构图、字体、主要物体与交互。向下滚动后保持同一深色
底色、同一文字色和同一条细线 / 坐标语言。章节边界通过光、构图与
留白区分；不再突然出现明亮的整页白色卡片。

01 / JOURNAL — 星夜中的思考
桌面采用“约 46% 常驻油画舞台 + 54% 编号文章目录”。
目录每行直接展示标题、短摘要、日期与类型；点击标题或整行直接阅读。
hover 或 keyboard focus 改变左侧画作的色调、光照与预览文字，预览不是
进入文章的前置步骤。至少三条标题在一个屏幕中可见。
画作方向：靛蓝、松绿、钴蓝的星空旋涡，一朵或一小簇暖金向日葵，
边缘以油画厚涂笔触融入宇宙。正文区域保持干净。

02 / LEARNING — 星图里的学习路径
避免再做一排同质卡片。每门教程是一条清晰路径：编号、标题、说明、
难度、状态。细线与少量节点产生星图联想，用户仍能直接打开教程。
旁边的油画窗口在活动路径改变时淡化为不同宇宙地景。
画作方向：莫奈式夜色水面、星云在水中的反光、遥远的暖色天体。

03 / WORKSPACE — 可直接使用的创造空间
优先显示最常用的 6–8 个工具入口，采用精确的两列清单或大字号命令
目录，而不是先打开一个装饰性大卡片才能发现具体工具。
保留“全部工具”直达入口。JSON / Markdown / 图片 / PDF 等常用类别
可以作为清楚的分组标签。数据来自现有工具目录。
3D 展品仅负责这一区域的空间识别：一张悬浮金属纸、轨道、花瓣卫星。
它不遮挡、替代或增加工具入口的点击步骤。

04 / GOOD FINDS — 好奇心花园
在宇宙向日葵 / 星云花园的宽幅背景前放置两个明确入口：值得一读、
私藏网站。显示真实数量，入口保持独立、宽大、可通过键盘聚焦。
可展示少量精选名称帮助判断内容，导航不隐藏在翻转、拖拽或悬停后面。

艺术一致性
背景：继续采用当前 Hero 的深色宇宙底色。
文字：暖白而非纯白；次级文字为能读清的浅灰绿。
色彩：向日葵金 + 松绿 + 少量钴蓝，金色集中在花心、星体与活动节点。
油画：厚涂笔触与星云、花瓣形成空间，避免整页铺满高对比纹理。
每个章节有一幅明确主画；文字放在画作的留白处或稳定暗色区域。

动效与访问规则
1. 单一方向：原生纵向滚动，所有锚点真实存在。导航始终可以直接跳转。
2. 章节进场：opacity + 12–24px 位移，画作可以有 4–7 度透视回正。
3. 活动场景：IntersectionObserver 确定当前章节，背景交叉淡化；不在
   每次滚动时 React setState，也不把页面锁成强制播放的影片。
4. 画作预览：hover/focus 可探索，click 一步访问；移动端点击仍直接访问。
5. 横向展览：只作为可选图片浏览，有可见前后按钮、序号和全部标题，
   不把唯一内容入口藏在横向轨道后半段。
6. 始终可读：链接、标题、日期和分类都保留在 HTML 中，Canvas 只管视觉。
7. 性能：只运行当前可见的场景；场景切换时最多保留两张活动纹理。
   图片预加载当前与下一张，DPR 上限 1.5，页面隐藏或离开视口后暂停。
8. 减少动态效果：保留最终静态构图和直接导航，关闭漂浮、视差与扭曲。

优先实施建议
先把全页背景 / 字体 / 边线统一，再把随笔、教程、工具从装饰卡片
重新组织成可快速扫读的目录；加入原创油画舞台后，最后添加章节淡入、
活动画面交叉淡化与克制的 3D 位移。最先验收“找到并打开内容”的效率。

最终落地 / 2026-10-03
保留已认可的首页星球首屏，全页采用深绿、古金与暖白的展厅配色。
随笔采用中央大画面与两侧透视画框，下方保留全部编号目录。目录悬停 /
键盘聚焦更新预览，点击直接阅读全文；前后按钮及方向键负责手动浏览。
轮播需显式开启，每 8 秒切换；手动浏览停止轮播，离屏或后台暂停。
学习区改为星环仪 + 航线目录：五条实际 CMS 路线可直接进入，选择时
联动预览和雕塑姿态。工具区改为三个用途分类 + 直接链接，共 11 个工具，
配以真实 Three.js 向日葵雕塑。收藏区采用全宽睡莲星池，并为网站入口
提供星空交叉淡化；数量取自现有收藏目录。
新增三个原创油画：星夜、向日葵、睡莲，WebP 总计约 1.4 MiB，沿用
同一深绿古金风格。没有复制参考项目的代码或图片。
原生纵向滚动，章节首次渐入，序章轻微滚动视差；全局暂停同时覆盖
WebGL、轮播、CSS 动画、过渡和平滑滚动。系统减少动态效果同样生效。
Three.js 共用一个异步运行时；后两处雕塑接近视口才加载，DPR 上限1.25，
离屏 / 后台停止帧循环，无 WebGL 时保留静态 CSS 展品与全部入口。
手机端采用单幅画作、可横向浏览的文章目录、紧凑学习预览及单列工具。
桌面和 390px 移动尺寸浏览器截图保存在 docs/qa-screenshots/cosmic-gallery/。

持续运动升级 / 2026-10-03
油画由静态展示升级为实时 WebGL 纹理：星空两个局部旋涡与大范围笔触
流动；向日葵花瓣环带和花心分别转动；睡莲岸线保持稳定，前景水面
产生水平波纹与反射变化。序章、随笔、收藏入口和独立收藏页共用
LivingArtwork。文字、目录和表单保持稳定，不参与画面的扭曲或旋转。
画廊每次仅活动画作初始化 Canvas，收藏入口也仅当前背景运行 Canvas；
替换时释放纹理、材质、几何体与 WebGL context。30fps、DPR 上限1.25，
接近视口加载，离屏、后台或全站暂停时不继续绘制。
真 3D 星环仪各环独立回转，卫星周游；向日葵花盘约45秒一圈，花瓣
约8秒呼吸周期并依次起伏。暂停或离屏保留当前姿态，恢复首帧无跳变。
文章、教程、收藏、工具目录及11个独立工具使用同一轻量轨道背景；
所有导航提供暂停开关，blog-motion 偏好跨文档保存，系统减少动效
和后台隐藏仅影响当前播放状态，不覆盖用户选择。浅色/深色均适配。
暂停 CSS 循环保留时间位置；一次性入场标记 data-motion-entry，在暂停
期间直接展示最终状态，防止切换分类后新内容停留在透明的第一帧。
验证：30个测试文件、173项测试通过；类型检查和生产构建通过；
13个页面、11个工具的构建入口与资源校验通过。Three.js共用异步块
532.05kB（gzip132.88kB）有体积提示，场景仍按需加载。
