# 个人网站改造记录与待办

审查日期：2026-09-29；基于 `origin/main` 的 `8e62715`，本地整理分支为 `codex/project-organization`。此文区分已实施改动、历史阶段与尚未完成的后台工作。

## 当前范围

用户先确认「暗色数字工作室」方向，随后要求保留原首页的个人表达与身份分类，最后指出工具、其他二级页面和深浅主题不一致。本轮在既有首页基础上，统一阅读页与工具工作台，并整理入口、逻辑、样式和主题边界。

### 已实施

- 首页保留「我的空间」、居中衬线「创造者 / 思考者 / 探索者」、个人简介、原栏目顺序；绿色轨道星球支持暂停与减少动态效果。随笔、教程和工具沿用蓝灰、紫、绿配色。
- 主题配色集中在 `src/styles/tokens.css`。React 与工具共用 `src/app/theme.ts`，同源跨页面、跨标签页及前进后退都读取相同偏好；首屏脚本仅提前应用颜色。
- 随笔和教程复用 `ArticleLayout`，标题、正文、评论对齐到同一阅读列。加载、连接失败、重试、内容不存在和未知路由 404 有明确状态。
- 正文与 Markdown 工具复用 `renderMarkdown`，支持标题、列表、代码块、链接、表格与引用，HTML 经消毒后展示。代码与表格在局部滚动，评论样式从页面样式中拆出。
- 评论前端对齐 `authorName` 字段，区分请求失败与空列表，提交失败保留草稿。服务端审核与邮箱隐私仍待独立验收。
- 11 个工具拆成根目录 HTML 入口、`implementations/` 处理模块和 `workbench/` 公共界面，统一上传区、表单、按钮、提示与深浅主题。
- `services/toolCatalog.ts` 同时服务首页、搜索与工具目录，工具入口始终不依赖 CMS。
- 工具改用 npm 打包依赖，移除 CDN 依赖；Vite 将主站与工具一起构建为完整 `dist/`，既有 `/mini-tools/*.html` 地址保留。

本轮通过 TypeScript 检查、75 项测试和生产构建；构建检查覆盖主站 + 12 个工具入口、11 个目录链接和全部 HTML 引用资源。浏览器检查了工具手机布局、深浅主题、主题跨页保持，以及 JSON、二维码、字数、时间戳、Markdown 的主要交互。文件工具测试通过真实 PDF 生成后重新解析、ZIP 生成后解包验证；图片压缩测试模拟了浏览器解码与 Canvas。阅读页用临时只读接口样本检查正文、长代码、表格和评论布局，未接入真实 Strapi 数据。这里的生产构建是本地产物检查，不代表已经发布上线。

## 项目运行边界

| 部分 | 当前职责 |
| --- | --- |
| React 主站 | 首页、内容阅读、评论界面、搜索与主题操作 |
| Vite 多页面工具 | 11 个浏览器工具与目录，和主站共用构建、主题与目录数据 |
| Strapi 5 | 已有随笔、教程、工具、评论 schema；旧后台尚未接回 |
| `content/` | 3 篇重写随笔及编辑记录，另有 5 篇教程及工具介绍稿；随笔可通过 `pnpm essays:sync` 同步到本地 SQLite |
| `public/` | 无需编译的静态资源与首屏主题脚本 |
| `docs/design/` | 已确认的首页融合稿及早期方案，仅作设计参考 |

仓库不包含原内容数据库和上传文件。本轮未安装/启动 Strapi、连接生产数据库、导入文章或执行种子写入。主站显示连接失败，不代表稿件已删除；启动空后台也不会恢复旧文章。临时只读样本用于检查渲染时，不能被称为恢复了真实内容。

```text

├── components/layout/          # 导航、页脚、共享阅读布局
├── components/ui/              # Markdown 正文、动效、主题按钮

│   └── search/                 # 全站搜索
```

## 设计原则

视觉依据是 [首页融合版](design/home-fusion.html)，[第一版数字工作室](design/digital-studio.html) 留作历史对照。用户认可的是原首页气质加绿色星球与三色卡片，后续应沿此方向迭代，不重新替换整套首页。

- 颜色集中维护深浅两套，不在业务页面另建调色板。
- 阅读页保持舒适行宽和正文层级，工具页优先让输入、设置、结果和操作清晰。
- 卡片 hover 与键盘 focus 都有反馈，手机不能依赖 hover 操作。
- 首屏动画轻量可暂停，尊重减少动态效果偏好。
- 所有交互接真实目标；概念稿示例文章不导入正式网站。
- 作品、阅读进度、目录、上一篇/下一篇等功能需另行确定范围，不将提案计为已实现。
