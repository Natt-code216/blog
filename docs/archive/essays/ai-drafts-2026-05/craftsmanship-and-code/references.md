# 参考资料 · 手艺与代码

- Andrew Hunt & David Thomas, *The Pragmatic Programmer*（20th Anniversary Edition, 2019, Addison-Wesley）— <https://pragprog.com/titles/tpp20/the-pragmatic-programmer-20th-anniversary-edition/>
  - 核心观点：程序员应当像手艺人对待自己的手艺一样对待代码，包括署名感、可维护性、长期视角。
- Pete Hodgson, "Architectural Refactoring" — <https://martinfowler.com/articles/refactoring-document-load.html>
  - 核心观点：好的代码不是一次写出来的，是一次一次小修改打磨出来的。
- Dan Abramov, "Things I Don't Know as of 2018" — <https://overreacted.io/things-i-dont-know-as-of-2018/>
  - 核心观点：再资深的工程师也始终在学。手艺的核心是承认不会，而不是假装全会。
- Software Craftsmanship Manifesto — <https://manifesto.softwarecraftsmanship.org/>
  - 核心观点：以"well-crafted software"为价值导向，反对"恰好能跑"的态度。
- 柳宗悦《工艺之道》— 广西师范大学出版社
  - 核心观点：手艺的美来自于"为他人使用"——好的器物是匿名的、是日常的、是经得起反复触摸的。
