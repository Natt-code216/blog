# Outline · 现代前端架构指南

按 6 章组织：
1. 为什么需要前端架构 —— 项目跨过 5 万行后的问题画像。
2. 路由与目录组织 —— from "按类型分类" to "按业务切片"。
3. 状态分层与跨层通信 —— server state / ui state / form state 三件套。
4. 数据获取与缓存 —— TanStack Query 心智模型、stale-while-revalidate、并发与取消。
5. 模块边界与代码分割 —— route-based split、动态导入、bundle 预算。
6. 架构演进与重构信号 —— 何时该重构、何时该忍。

每章 ≥1500 字，至少一段可读代码或伪代码。
