# 参考资料 · 从零搭建 React + Vite + TypeScript 项目

- Vite 官方文档 — <https://vitejs.dev/>
  - 核心观点：ESM 原生 + esbuild 预构建，让 dev server 几乎瞬启。
- React 官方文档 — <https://react.dev/>
- TypeScript 官方手册 — <https://www.typescriptlang.org/docs/handbook/>
- Anthony Fu, "Reimagine Atomic CSS" — <https://antfu.me/posts/reimagine-atomic-css>
- Mark Erikson 关于 React + TS 配置的多篇文章 — <https://blog.isquaredsoftware.com/>
- Patak, Bjorn Lu 等 Vite 维护者的会议演讲 — <https://www.youtube.com/@vite_official>
- Matt Pocock, *Total TypeScript* — <https://www.totaltypescript.com/>
  - 核心观点：tsconfig 选项可被分成"几乎必开"与"按需开"两类，先把第一类配齐。
- Rollup Plugin Visualizer — <https://github.com/btd/rollup-plugin-visualizer>
