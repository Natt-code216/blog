# Web 极致性能优化

速度本身就是一种功能。一个慢半秒加载的页面，跳出率会显著上升；一个滚动卡顿的应用，无论功能多好都会被默认为"不好用"。

本系列覆盖五章：

1. **Web Vitals 心智模型**——LCP、INP、CLS 这三项是 Google 用来描述用户体验的核心指标，理解它们是优化方向的起点。
2. **关键渲染路径**——HTML 到第一个像素之间，浏览器到底在做什么？
3. **字体与图片加载**——这两类资源占据首屏体积的 60%+，但优化方式截然不同。
4. **HTTP/3 与缓存**——网络层能做的事比大多数人意识到的多。
5. **Service Worker 与离线策略**——离线优先是 PWA 时代的新现实。

每一章都假设你已经写过两年以上前端项目，且至少做过一次 Lighthouse 跑分。我们不讨论"是不是该用 React"，只讨论"已经用了某框架的项目，怎么把它跑得更快"。
