# UI/UX 美学与极简设计

写这个系列前，我做了一个统计：过去三年里我接手过的十几个项目，刚拿到设计稿时第一个感受不是"设计水平如何"，而是"这套设计能不能落"。

"能不能落"这件事和审美没有直接关系。它关心的是几个非常具体的问题：间距是不是有规律？色板是不是有限封闭？文字层级是不是清晰可数？暗色模式是不是另一套独立的色卡，而不是简单反色？

这些问题如果一开始没回答好，到了开发阶段就会变成无穷无尽的"按这个 Figma 像素对一下"的争论。如果一开始回答得好，开发阶段几乎不需要争论——设计师和开发者用同一组令牌说话。

本系列把这些问题分成 5 章，每一章都聚焦于一个可落地的子系统：

1. **字重 · 行高 · 度量** —— 排版的三件套，影响 80% 的可读性。
2. **色彩与对比度** —— 灰阶系统、WCAG AA/AAA、可访问性的真实门槛。
3. **留白与节奏** —— 用一组间距阶梯让页面有呼吸感。
4. **组件令牌化** —— 把设计稿翻译成可复用的 design tokens。
5. **暗色主题专题** —— 灰阶倒置不是反色，是另一套独立的判断。

## 阅读姿态

这不是一篇"如何成为大师设计师"的教程。它的目标更朴素——让一个有审美直觉但缺乏系统训练的开发者 / 半设计师，能搭出一套**不会让自己每周都纠结**的视觉规范。

如果你已经是一位资深视觉设计师，本系列的内容对你来说大都是"我早就在做的事"——这是好事。本系列的真正读者是那些"知道好坏，但不知道怎么把好坏写成规则"的人。

## 一句话基线

如果只能记住一句话：好设计是一组"小决定的复利"，而不是某个灵光乍现的总体方案。每一个间距、每一个灰度、每一处行高的选择，都是这复利里的一份子。
