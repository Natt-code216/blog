# 图片转 PDF

把多张图片合并为一份 PDF，全部在浏览器本地处理。

## 功能

- 支持 JPG、PNG、WebP 输入。
- 可选页面尺寸（A4 / Letter / 自适应原图）。
- 拖拽调整图片顺序。
- 一键导出 PDF。
