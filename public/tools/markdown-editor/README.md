# Markdown 沉浸创作

双栏所见即所得的 Markdown 编辑器，自动保存草稿到本地。

## 功能

- 左编辑、右预览，实时渲染。
- 草稿自动保存到 `localStorage`。
- 一键导出 HTML / 纯文本 / 复制到剪贴板。
- 顶部显示实时字数。

## 第三方依赖

- [marked](https://github.com/markedjs/marked) — MIT License
- [DOMPurify](https://github.com/cure53/DOMPurify) — Apache-2.0 License
