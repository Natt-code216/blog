# 参考资料 · Web 极致性能优化

- web.dev Performance — <https://web.dev/explore/learn-core-web-vitals>
  - 核心观点：LCP / INP / CLS 三项指标覆盖了用户对"加载-交互-视觉稳定"的核心感知。
- Addy Osmani, *Image Optimization in Modern Web Apps* — <https://images.guide/>
  - 核心观点：图片是 web 首屏体积最大的来源，最值得花精力的优化往往集中在这一块。
- Houssein Djirdeh, *Web Performance Calendar* 系列文章 — <https://calendar.perfplanet.com/>
- Lighthouse 文档 — <https://developer.chrome.com/docs/lighthouse>
- Patrick Meenan, "HTTP/3 deep dive" — <https://blog.cloudflare.com/http3-the-past-present-and-future/>
- Jake Archibald, "Caching best practices" — <https://jakearchibald.com/2016/caching-best-practices/>
- Service Worker Cookbook — <https://serviceworke.rs/>
- Ilya Grigorik, *High Performance Browser Networking* — <https://hpbn.co/>
