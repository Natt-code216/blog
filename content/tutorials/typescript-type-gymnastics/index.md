# TypeScript 类型体操与领域建模

很多开发者对 TypeScript 的认识停留在"给变量加类型注解，让 IDE 自动补全"。这只是 TS 能力的 5%。

剩下的 95%——条件类型、模板字面量、mapped types、判别联合——能让你**用类型表达业务规则**。一旦做到这一点，运行时代码中至少一半的 if/else 会自然消失。

本系列六章，循序渐进：

1. **基础回顾**——never / unknown / 类型守卫，是后面所有类型体操的基石；
2. **条件类型**——`T extends X ? A : B` 与 `infer`；
3. **模板字面量类型**——字符串级别的类型计算；
4. **Mapped Types**——字段级转换的核心工具；
5. **判别联合与状态机**——把流程用类型显式表达；
6. **用类型表达业务不变量**——让"坏状态"在编译期就不存在。

## 阅读门槛

- 至少写过半年 TypeScript；
- 对泛型、函数重载、类型推断有基础认识；
- 用过 `Partial<T>`、`Pick<T, K>` 这类工具类型。

## 关于"类型体操"这个词

"类型体操"听起来像炫技，但本系列的目的不是炫技。它的目的是：把类型变成**真正的设计工具**，而不只是注解工具。

读完本系列之后，你看到一段代码不会再先看运行时逻辑，而是先看类型——因为类型已经表达了"这段代码做什么"。
